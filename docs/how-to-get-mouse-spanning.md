# 怎么真正做到"鼠标跨两块屏" —— 三条路执行清单

> 你是 OPPO Pad Mini（Snapdragon 8 Gen 5 / Android 16 / 官方 ColorOS）。
> 你要的"一个鼠标从平板滑到外接显示器"，Android 官方叫 **Connected Display**，
> 但 OPPO 出厂时把它**关掉了**，普通 App 改不了（我这几版已经验证过）。
>
> **下面是能真正做到的办法。选一条，照着做。**

---

## 路线 A：给显示器配个鼠标 —— **今天就能用，几十块钱** ⭐ 最省事

### 做什么

买一个**便宜的无线鼠标**（USB 接收器 或 蓝牙都行），
**USB 的直接插在显示器的 USB 口上**（大多数显示器都有）。

### 结果

外接屏有了**自己的鼠标**，**立刻可用**。

### 优点 / 缺点

- ✅ 今天就能用，不花钱太多，不动系统，零风险
- ✅ 不需要 PadDisplay、不需要 Shizuku、不需要 root
- ❌ 是"两个鼠标"，不是"一个鼠标滑过去"

### 如果你选这条

PadDisplay 仍可用来调**分辨率 / 刷新率 / 内屏开关 / 音频路由**（这些是真有效的）。

---

## 路线 B：解 BL → ROOT → 装 LSPosed 模块 —— **保住 ColorOS，能开桌面模式** ⭐ 最对路

这是**不开刷第三方 ROM、只用官方 ColorOS** 就能达成目标的办法。

### 为什么可行（已查证）

有一个专门的 LSPosed 模块，功能就是打开开发者选项里
**"Enable desktop experience features"**，从而启用外接屏桌面模式：

- 模块：https://github.com/igorb200828/Android_16_Desktop_Experience_Enabler
- 它需要用 LSPosed 加载 → 所以需要 root

### ⚠️ 时间门槛（重要，今天就该开始）

一加/OPPO/realme 的官方解锁工具叫 **「深度测试」**，但政策要求：

> **账号需注册满 60 天、完成实名认证**

**所以：如果你还没注册 OPPO/一加账号，今天就去注册并实名。**
60 天后才能申请解锁。这一步不花钱，但**有时间成本，越早开始越好**。

### 执行步骤

| 步骤 | 做什么 | 备注 |
|---|---|---|
| 1 | 注册 OPPO / 一加账号 + **实名认证** | **今天就能做，立刻开始计时（60 天）** |
| 2 | 等满 60 天 | 期间可以做路线 A，先用起来 |
| 3 | 下载官方**「深度测试」**App，申请解锁 | 全机型通用工具 |
| 4 | 解锁 bootloader | ⚠️ **会清空全部数据**，先备份 |
| 5 | 刷入 Magisk 获取 root | 用 ROM乐园等现成资源（已确认有 OPPO Pad Mini 专版） |
| 6 | 安装 LSPosed 框架 | |
| 7 | 安装并启用上面那个桌面模式模块 | |
| 8 | 连显示器测试鼠标跨屏 | |

### 优点 / 缺点

- ✅ **保住 ColorOS**，不用换系统，原有的平板功能都在
- ✅ 官方解锁通道，不用第三方破解
- ❌ 需要等 60 天
- ❌ 解锁会清空数据；root 后部分银行/支付类 App 可能拒绝运行
- ❌ 不能 100% 保证成功（`display_topology` 是编译期开关，**root 也未必能改**；
      只有 `config_isDesktopModeSupported` 可能被该模块绕过）→ **有失败概率**

### 先花 5 分钟验证可行性（强烈建议）

在等 60 天的期间，**不用 root 也能查一件事**：

用 **Shizuku**（你已经装了）在 PadDisplay 里执行，或者用电脑 adb：

```
adb shell dumpsys display | findstr /I "unique topology"
adb shell getprop | findstr /I "desktop"
```

如果 `display_topology` 相关能力完全不存在，说明这个 ROM 把它删干净了，
那 root 也可能救不回来 → **就该考虑路线 C**。

## 路线 C：换一台官方支持的设备 —— **最稳，插上就能用** ⭐ 最终答案

### 为什么

Android 官方的"鼠标在两块屏之间自由穿梭"**只对厂商开放了开关**。
官方博客**点名的型号是三星 Galaxy Tab S11**（DeX 系列平板）。

### 结果

插上显示器 → **鼠标直接跨屏**。不用 root、不用刷机、不用任何 App。

### 优点 / 缺点

- ✅ **100% 确定能用**，官方原生体验，零折腾
- ✅ 三星 DeX 本来就是这套体验的标杆
- ❌ 要花钱

### 如果你选这条

现在这台 OPPO Pad Mini 可以留着日常用，或者二手出掉。
