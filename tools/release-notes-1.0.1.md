# PadDisplay v1.0.1

本版集中修整前端和自有桌面的生命周期，保留已正常的鼠标、显示、缩放与音频功能。

- 参考三星 DeX / 华为桌面模式：横向桌面、左侧快捷方式、右上角时钟、底部完整任务栏与控制区。去掉挤在一起的顶栏和居中大时钟，重新绘制自有渐变壁纸。
- 将 PadDisplay 自己的桌面任务明确切为全屏并清除旧窗口边界，修复桌面继承自由窗口后变成居中竖条的问题；其它应用仍可自由窗口或全屏。结果读回失败时保留诊断。
- Dock 不再只等收藏：按本机实际安装的浏览器、文件管理、设置、相册、便签、远程应用选取默认项，用户收藏优先；无 Google 套件也能正常显示。SIM 工具不加入默认 Dock。
- 桌面前台使用内置完整任务栏，应用前台使用原有悬浮 Dock，减少重复浮层。
- 退出时结束并移除自有桌面和导航任务，清理悬浮层；只迁回本次主机模式启动的应用，跳过混有其它任务的共享根任务。避免遗留自己的桌面任务记录。
- 主机启动不再切换整块显示器的窗口策略；只调整 PadDisplay 自己的桌面任务，不改 ColorOS 厂商配置、桌面启动器或调度机制。

验证：release 构建、签名与安装；OPPO 应用列表的无 Google / 空收藏 Dock 检查、F9 / Alt 规则、窗口布局和 DPI 异常检查；无 Google 应用的模拟器桌面预览。

没有可连接的 OPPO 真机。自有桌面全屏和退出后的再次回桌面需实测；若仍出现其它应用留在外屏，本版不会强改厂商策略或关闭不属于本次会话的应用。
