## 屏幕左右关系：找到了正确 API

AOSP DisplayManagerService 中：
    if (mFlags.isDisplayTopologyEnabled()) {
        DisplayTopologyGraph graph = update.second;
        mInputManagerInternal.setDisplayTopology(graph);   // 喂给输入系统
    }

DisplayTopology 不只是画位置图 —— 它建立多屏统一坐标空间并驱动 InputManager，
这正是 Android 里指针/输入跨屏的机制。所以"左右关系"和"光标跨屏"是同一件事。

必须探测，因为 flag 关闭时服务端：
    getDisplayTopology() -> mDisplayTopologyCoordinator == null 时返回 null
    setDisplayTopology() -> coordinator 为 null 时静默空操作，不报错

所以本版：先探测 -> 写入 -> getDisplayTopology() 读回验证，
读回不一致就明确告知"本机关闭了该能力"，不给假的成功。

## 键盘为什么不绑

Android 输入设备关联是静态绑定（设备到屏幕），没有"键盘跟随焦点动态切换"。
但键事件走焦点窗口：点哪块屏哪块屏获焦，键盘就往哪里输。
所以正确做法是把鼠标绑到外屏、键盘不绑。
