v0.3.3: 界面重排（一键开始 / 一键还原 + 高级选项折叠 + 上下左右）

## 前端重做

之前把 8 个功能平铺一页、按钮几十个，用户不知道该点哪个。现在打开只有两件事：

  系统状态（Shizuku / 外接屏）
  ① 一键开始（外接屏独立显示）
  ② 一键还原所有设置
  ▶ 高级选项（点开查看更多）  ← 其余全部收在这里，默认收起

### ① 一键开始

按顺序自动完成：
1. 外接屏切独立显示（去黑边）
2. 平板内屏保持点亮
3. 声音切回平板侧（耳机/扬声器），防止显示器抢音频
4. 在外接屏打开应用，形成第二个桌面

### ② 一键还原（救命按钮）

恢复本应用改动过的所有系统级状态：
  内屏：先点亮，再还原窗口模式为 FULLSCREEN
  输入设备：解除全部关联
  音频：清除媒体策略固定 + 通话固定
  显示拓扑：写回改动前保存的快照
  尺寸/Mode：清除逻辑尺寸覆盖 + 重置用户首选 Mode

顺序刻意设计为先点亮内屏，所以即使黑屏也能救回来。点之前有确认弹窗。
若 Shizuku 已断开导致还原无效：重启设备一定能恢复（系统态不落盘）。

### 拓扑快照

为了让一键还原能真的还拓扑，本版在改拓扑之前自动保存一份原始快照
（存在 UserService 私有目录），还原时写回。之前只改不存，是还不回来的。

### 屏幕位置四方向

补全：在左 / 在上 / 在右 / 在下，对应 AOSP TreeNode.POSITION_LEFT/TOP/RIGHT/BOTTOM。
（本机 DisplayTopology feature flag 关闭，这四个按钮目前大概率仍报未生效，
但不隐藏，因为需要看到试过以及为什么不行。）

### 其余按钮

全部移进「▶ 高级选项」：显示器详情、关屏开屏、显示模式、黑边/镜像诊断、
音频输出、分辨率与刷新率、Mode 自检、自动操作开关、手动指定屏幕角色、
输入绑定、屏幕位置、坐标空间排查。

## 新增/修改文件

- MainScreen.kt：PrimaryActionsCard（两个大按钮 + 确认弹窗）、AdvancedToggleRow、
  LazyColumn 结构重排、四方向按钮

  UiState.advancedExpanded
- SystemDisplayService.kt：restoreAll / oneClickExtend

  setLayout 支持四方向
