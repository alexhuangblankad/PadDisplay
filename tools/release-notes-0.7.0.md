# PadDisplay v0.7.0

- 新增内屏桌面控制台、应用图标网格、搜索、收藏和独立外屏桌面。
- 新增物理外屏任务栏及真实任务切换、关闭、自由窗口排列/移动/缩放；系统不支持时报告失败。
- 外屏 DPI 支持 75%–200%，带倒计时恢复和显示器配置记忆。
- 保留原显示、4K/刷新率、内屏电源、音频与诊断控制台。
- 修复鼠标枚举、三级关联回退与实际显示归属读回，加入会话退出及断线恢复。
- Moonlight 前台可隐藏任务栏，鼠标仍由系统原生处理。

独立实现，没有复制 VoyageOS 代码或绕过其收费。真实 ColorOS 外屏功能仍待设备验证；本版不提供原生双屏鼠标跨边缘流转，不能承诺所有应用支持自由窗口。
