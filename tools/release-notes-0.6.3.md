# v0.6.3：主机模式入口与外屏缩放

- 新增主机模式：内屏应用列表，鼠标静态关联到外屏，关联结果以读回为准。
- 新增外屏界面大小 75%–200%：DPI 调整、确认倒计时、超时回滚与原缩放恢复。
- 应用列表支持搜索，不再仅显示前 40 项。
- 修复一键还原无条件返回成功；保留失败原因及恢复快照。

这是 PadDisplay 的独立实现，不包含 VoyageOS 代码或资源，不修改其授权系统。
没有实现 VoyageOS 完整桌面与多窗口管理；没有实现内外屏鼠标连续迁移。
没有可连接 OPPO 真机，光标、缩放与 Moonlight 行为待验证。

验收与分析见 docs/voyage-apk-analysis.md。
