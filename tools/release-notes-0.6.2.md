# v0.6.2：鼠标原生关联验证修复

- 修复绑定成功判定：以所有目标鼠标的关联读回为准，不再凭写接口返回成功显示完成。
- 直接通过 Binder 获取新鲜输入设备信息，等待异步关联更新，并按 descriptor 匹配设备。
- 三级回退现在覆盖“接口返回正常但关联不生效”，回退前解除上一条无效映射。
- 设备列表增加鼠标/键盘类型、descriptor、关联显示器 ID 与读回失败原因。
- 解除关联保留失败原因，排除内置设备与纯键盘，并验证鼠标恢复为未关联状态。
- 提示复合鼠标/键盘设备的设备级关联限制。

本次没有连接 OPPO 真机。鼠标固定到外屏、外屏原生光标和 Moonlight 行为均待实测。
本版本没有实现两块物理屏之间的连续鼠标流转。

验证步骤见 docs/input-routing-validation.md。
