## 先认一个错：前端是我做乱了

之前我把 8 个功能平铺在一页，按钮几十个，**你当然不知道该点哪个**。这是我的问题。

## 现在的结构（打开只有两件事）

```
系统状态（Shizuku 通不通 / 有没有外接屏）

① 一键开始（外接屏独立显示）        ← 你要的效果，就按这一个
② 一键还原所有设置                  ← 出任何问题，按这一个

▶ 高级选项（点开查看更多）           ← 其余全部收在这里，默认收起
```

### ① 一键开始

按顺序自动做完：

1. 外接屏切独立显示（去黑边）
2. 平板内屏保持点亮
3. 声音切回平板侧（耳机 / 扬声器），防止被显示器抢走
4. 在外接屏上打开一个应用，形成第二个桌面

### ② 一键还原（救命按钮）

把本应用可能改动过的**所有**系统级状态恢复原样：

| 项 | 还原动作 |
|---|---|
| 内屏 | **先点亮**，再还原窗口模式为 FULLSCREEN |
| 输入设备 | 解除全部关联 |
| 音频 | 清除媒体策略固定 + 通话固定 |
| 显示拓扑 | 写回改动前保存的快照 |
| 尺寸/Mode | 清除逻辑尺寸覆盖 + 重置用户首选 Mode |

**顺序是刻意设计的：先点亮内屏。** 所以哪怕你正黑屏、什么都看不见，
点这个按钮（或者让别人帮你点）就能救回来。

点之前有确认弹窗，避免误触。

> 万一 Shizuku 已断开导致还原无效：**重启设备一定能恢复**（这些系统态都不落盘）。

### 拓扑快照

为了让"一键还原"能真的还拓扑，本版在**改拓扑之前自动保存一份原始快照**
（存在 UserService 私有目录），还原时写回。之前只改了不存，是还不回来的。

## 屏幕位置：左右之外补上上下

按你说的补全四方向：

```
[在左] [在上] [在右] [在下]
```

对应 AOSP `TreeNode.POSITION_LEFT/TOP/RIGHT/BOTTOM`。

（提醒：本机的 `DisplayTopology` feature flag 是关闭的，所以这四个按钮
目前大概率仍会报"未生效"。**我没有把按钮藏起来**，因为你需要看到它试过、
以及为什么不行；一旦 `⑦ 探测是否支持` 返回 true，它们就能用。）

## 其余按钮去哪了

全部移进「▶ 高级选项」：

- 显示器详情（内屏 / 外屏）
- 关闭/重开平板屏幕
- 显示模式（扩展 / 复制 / 仅外接屏）
- 黑边/镜像诊断与修复
- 音频输出选择
- 分辨率与刷新率、最佳分辨率、清除尺寸覆盖、Mode 自检
- 自动操作开关、手动指定屏幕角色
- 输入绑定、屏幕位置、坐标空间排查

**平时你完全不用打开它。**

## 请这样试

1. 连上外接屏 → 点 **① 一键开始** → 看结果
2. 如果哪里不对 → 点 **② 一键还原** → 回到干净状态

先别碰高级选项。等你确认这两个按钮行为符合预期，我们再进高级里逐项调。
