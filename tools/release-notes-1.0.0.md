# PadDisplay v1.0.0

本版将物理外屏控制台升级为独立桌面，并保留原来的显示、鼠标、音频与内屏电源功能。

- 加入菜单栏、渐变桌面、应用启动台、收藏和图标 Dock。修复桌面 Dock 依赖悬浮权限的问题：桌面内置 Dock 始终可用，跨应用悬浮 Dock 单独检查权限。
- 增加右下角返回 / Home / 多任务。Home 返回外屏桌面，多任务展示外屏任务，返回定向到物理外屏；不添加屏幕边缘手势拦截层。
- 增加可选全局 F9 全屏导航快捷键，启用快捷键辅助服务后唤出底部中央三键，面板临时获取焦点并在 15 秒后关闭。Fn+F9 需键盘上报 F9；左 Alt、Ctrl/Alt/Shift 修饰的组合和其它按键放行，保留 UU 自己的鼠标切换逻辑；不处理鼠标或读取窗口内容。
- 自由窗口提供关闭、返回桌面、全屏、恢复窗口、位置和尺寸控制。可见 freeform 任务提供拖动标题条与调整手柄，松开后提交并读回边界。系统拒绝 freeform 时明确报告，避免把全屏回退显示为成功。
- 控制中心提供媒体音量、平板亮度、Wi-Fi / 蓝牙系统设置和主题切换；复杂显示与音频功能集中到高级设置。
- 支持亮色、暗色、跟随系统；主页简化并下移，保留内屏电源快捷按钮。
- 退出主机撤掉外屏前端和悬浮层，尝试将应用迁回平板、恢复原窗口策略与 DPI，鼠标明确关联回内屏，让系统恢复刚连接显示器时的效果。移除 FULLSCREEN=扩展的错误状态推断。
- 保留 4K / 显示模式、75%–200% 外屏缩放、音频路由、热插拔恢复和 Moonlight 前台隐藏浮层。

验证：release 构建、APK 签名、模拟器安装、亮暗桌面 / 控制中心 UI、实际音量调整、5000 组窗口布局和 DPI 异常路径检查通过。用户此前确认鼠标、缩放、显示正常。

本轮没有可连接的 OPPO 真机：新增外屏悬浮层、任务回迁、窗口操作、平板亮度需 ColorOS 实测。黄色窗口按钮是返回桌面，不是最小化；拖动和调整在松开时应用；侧边返回依赖系统派发。没有实现原生鼠标跨两屏边缘流转。

全屏导航快捷键需在系统辅助设置开启服务，尚未在 OPPO 的 Moonlight / UU 串流中验证，不能保证每种键盘都会上报 Fn+F9。快捷键规则和导航面板 UI 单独检查，保留高级设置手动唤出入口。

仅发布签名 release APK，兼容原应用升级。详细使用和限制见 README 与 docs/desktop-guide.md。
