# PadDisplay v1.0.3

优化桌面视觉，并针对“外屏输出 4K、应用可能沿用内屏配置”补齐启动参数与诊断。该原因是用户观察后的假设，尚没有 ColorOS 任务配置证据。

- 启动前通过 ActivityOptions 提交物理外屏 ID、窗口模式，以及按 WindowManager 当前外屏逻辑工作区计算的窗口边界；接口失败保留原 am 启动回退。
- 窗口页展示目标应用的实际 displayId、dp 尺寸、DPI 和 appBounds，区分输出分辨率、逻辑工作区和应用配置。
- 保留窗口模式与边界共同验证、最近任务恢复重试，不修改厂商显示策略，不强改应用可调整属性。
- 标题条使用全屏坐标原点，避免系统栏 inset 重复偏移。
- 重绘亮暗渐变桌面，去掉大时钟和波浪背景；缩小任务栏图标，统一线条导航、分隔与鼠标悬停反馈。默认快捷方式仍来自本机实际安装应用。

验证：release 构建、签名与模拟器安装；亮暗桌面和控制中心视觉检查；无 Google Dock、F9/Alt、5000 组窗口布局、应用配置解析与 DPI 异常检查通过。

尚无 OPPO 真机连接，不能宣称已解决所有应用的自由窗口、2520×1680 配置继承或厂商兼容缩放。

布局参考：[三星 DeX 官方说明](https://www.samsung.com/us/support/answer/ANS10002880/)，图形与代码独立实现。
