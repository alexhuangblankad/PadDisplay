用户已实测 4K 全屏成功，本版重点补全全屏导航入口。

- 外屏底边 8dp 热区：鼠标停留两秒或点击即可请求 Dock、三键和窗口按钮，15 秒后收起，左右留出系统侧边手势空间。
- 平板的主机模式通知增加“唤出导航”，作为快捷键或鼠标捕获时的备用入口。
- 辅助服务连接时重新请求按键过滤；Alt+Shift 同时检查修饰键实际 down/up，单独 Alt 继续放行。
- 先显示浮层再尝试导航焦点对话框，避免对话框启动失败阻止全部菜单。

热区不申请焦点或鼠标捕获、不注入鼠标。Moonlight/UU 捕获鼠标时可能无法产生热区 hover，应用也可能隐藏普通浮层；平板通知入口不依赖 hover。全局快捷键仍需用户启用原快捷键辅助服务，Fn+F9 需键盘实际上报 F9。

自由窗口仍未达成：用户真机截图任务 mode=1，真实 enable_freeform_support=0、桌面模式=0、feature=false；本版不改厂商系统策略或自动写这些设置。
