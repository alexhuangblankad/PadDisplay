# PadDisplay v0.8.0

- 修正退出主机时的鼠标恢复策略：先点亮内屏，再清理旧关联并明确关联回内屏，读回验证实际 displayId。高级设置提供“鼠标回平板”。
- 首页只保留主机开启、退出恢复、内屏电源和应用区；其它操作放进高级设置。
- 添加亮色、暗色、跟随系统，统一文字对比度、圆角与卡片；内容位于状态栏安全区下方，额外下移 28dp。
- 高级设置按桌面/外观、显示、音频、窗口、诊断组织，移除旧触控板与指针注入实验入口。
- 外屏默认是壁纸、时钟、收藏快捷方式和图标 Dock；应用网格改为按需打开的启动台。
- 默认尝试自由窗口，增加真实任务全屏/恢复窗口、关闭和尺寸控制。悬浮控制条的黄色按钮返回桌面，不声称将所有窗口最小化。

构建和 UI 检查通过不等于 ColorOS 实测：鼠标归属回内屏、Dock 与任务窗口操作仍需 OPPO 验证。ROM 或应用不支持自由窗口时保留错误，不转发或注入鼠标。
